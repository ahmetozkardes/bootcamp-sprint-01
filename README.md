## 🧠 Projects

### 1️⃣ Grade Calculator
Calculates semester grade based on midterm and final scores and determines the letter grade.

**Concepts practiced:**
- Mathematical calculations
- Conditional logic
- Returning objects from functions

---

### 2️⃣ Rock-Paper-Scissors Game
A simple game implementation where the user plays against the computer using random selection.

**Concepts practiced:**
- Random number generation
- Game logic
- Function design
- Conditional comparisons

---

### 3️⃣ Lottery System
Selects specific indexed participants and adds a random winner from the remaining list.

**Concepts practiced:**
- Array slicing
- Array spreading
- Random index selection
- Working with copies of arrays

---

### 4️⃣ Donation Calculator
Counts how many times the letters from the name **"Ahmet" (a, h, m, e, t)** appear in donor names and calculates the total donation amount.

Each matching letter contributes **1000 TL** to the total donation.

**Concepts practiced:**
- Nested loops
- String manipulation
- Case normalization
- Algorithmic thinking

---

## ▶️ How to Run

Make sure you have Node.js installed.

Install dependencies (if any): npm install
Run the project: npm start
Or directly: node src/index.js
